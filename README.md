An entry for the [make.fun bounty "One-Liner Marathon"](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2): one one-line comedy joke, up to 280 characters, judged head to head on how hard it lands.

## The entry

> I let my AI assistant answer my emails — my boss promoted the fake me, and now I take orders from myself.

105 characters, one line. The joke is a worker who outsourced his inbox to an AI, only for the boss to promote the imitation — and now the original takes orders from himself.

## Run

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (or to `$OUTPUT_PATH` for a local run).
